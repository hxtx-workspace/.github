## 新项目如何加入

在 [`projects.json`](https://github.com/hxtx-workspace/.github/blob/main/projects.json) 增加一条项目配置，提交后会自动更新主页。仅显示已有项目的分类。

命名：`ios-tweak-<插件名>` · `web-<项目名>` · `ai-<项目名>` · `tool-<工具名>`。全部小写，多词用短横线；版本使用 Git 标签。
